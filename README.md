## 🛠️ Tech Stack & Architecture

* **Framework**: [Next.js 16 (Turbopack + App Router)](https://nextjs.org)
* **Frontend**: [React 19](https://react.dev), TypeScript
* **Styling**: [Tailwind CSS v4](https://tailwindcss.com) with custom dark glassmorphism design tokens
* **UI Components**: [shadcn/ui](https://ui.shadcn.com) (`@radix-ui/react-dialog`, `sonner` toast alerts)
* **Icons**: [Lucide React](https://lucide.dev)
* **Visuals & 3D**: [Three.js](https://threejs.org), `canvas-confetti`
* **Email Engine**: [Brevo (Sendinblue) REST API](https://api.brevo.com) via server-side route `/api/send-email`
* **Client Storage**: LocalStorage with schema validation for offline data persistence

## ⚡ Quickstart & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/mauryasapna/nexuslabs.git
cd nexuslabs
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
# Brevo Transactional Email API Configuration
BREVO_API_KEY=your_brevo_api_key_here

# Verified Sender on Brevo
BREVO_SENDER_EMAIL=sapnassm62062@gmail.com

# Destination Inbox for Leads & Inquiries
BREVO_RECIPIENT_EMAIL=nexuslab27@gmail.com
```

### 4. Start Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
